# Introduction to Programming with R

## RStudio Materials Directory

This directory holds a set of R Notebooks that can be used to teach
**Introduction to Programming with R** in an RStudio environment. This
is a good choice, if you are able to create and RStudio environment that
is the same for all participants.

There are a set of three notebooks for each of the two parts of the
Workshop: “Basic Syntax and Operators” and “Control Flow and Functions”.

## Basic Syntax and Operators

-   `Basic_Syntax_and_Operators.Rmd` This is the file students and
    instructor should work in during the workshop. The code chunks are
    not filled in.

-   `Basic_Syntax_and_Operators_Code_Chunks.Rmd` This file will be used
    by the instructor to provide the code that will be used in each code
    chunk. Headings are included and the chunk name will help identify
    what part of the notebook the code goes to.

-   `Basic_Syntax_and_Operators_Answers.Rmd` The instructor should refer
    to this prior to giving the Workshop to understand the material and
    format of the workshop. Students can refer to this file once they
    have completed the workshop. It contains the workshop and quiz code
    chunks.

## Additional Files

-   `Example_script.R` an example of an R script so students can see the
    difference between a notebook and a script.

-   `data` and `output` directories (used during section about
    `packages`)

    -   `data` directory has an excel spreadsheet that will be loaded in
        second part of workshop

    -   `output` directory will hold a file that gets written out during
        the second part of the workshop
