# READ ME

The Colab Materials directory contains:
* `Basic_Syntax_and_Operators.ipynb`
* `Basic_Syntax_and_Operators_Answers.ipynb`
* `Control_Flow_and_Functions.ipynb`
* `Control_Flow_and_Functions_Answers.ipynb`

These files were created using the python [`jupytext`](https://pypi.org/project/jupytext/) package. This package converts `.Rmd` files to `.ipynb` files.

Instructors and students should use  `Basic_Syntax_and_Operators.ipynb` and `Control_Flow_and_Functions.ipynb` during the workshop (unfilled). Students can refer to `Basic_Syntax_and_Operators_Answers.ipynb` and `Control_Flow_and_Functions_Answers.ipynb` after the workshop for review.
